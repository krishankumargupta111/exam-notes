# 🚀 Exam Notes AI – AI-Powered Notes Generator

An AI-powered notes generation platform that helps students create, manage, and download study notes effortlessly. Built using the MERN stack and Google's Gemini AI API, the application provides an intuitive way to generate educational content with a credit-based usage system.

## 🌟 Features

- **AI-Powered Notes Generation:** Generate structured study notes using Google Gemini AI.
- **User Authentication:** Secure authentication and user management.
- **Notes History:** Access and manage previously generated notes.
- **PDF Download:** Download generated notes in PDF format.
- **Credit-Based System:** Manage AI generation usage through a credit-based system.
- **Payment Integration:** Integrated Stripe payment gateway for purchasing credits.
- **Responsive UI:** User-friendly interface optimized for different screen sizes.
- **Cloud Deployment:** Frontend and backend deployed using Render.

## ⚙️ Getting Started

Follow these instructions to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/krishankumargupta111/exam-notes.git

cd exam-notes
```

### Start the backend:

```bash
npm run dev
```

### Start the frontend:

```bash
npm run dev
```
