# 🚀 AI Notes Generator

An advanced AI-powered Notes Generator built to transform lengthy content into smart, concise, and structured notes using the Gemini API. The application helps students, developers, and professionals generate high-quality study notes instantly while managing usage through a credit-based system.

Designed with scalability, performance, and modern UI/UX practices in mind.

---

# ✨ Features

## 🧠 AI-Powered Notes Generation

* Generate intelligent summaries using the Gemini API
* Convert long paragraphs into structured notes
* Fast and accurate AI responses
* Clean formatting for better readability

## 📄 PDF Download Support

* Download generated notes as PDF
* Easy sharing and offline access
* Professional formatting for study material

## 🕘 Notes History System

* Save generated notes automatically
* Access previous notes anytime
* Organized user history dashboard

## 💳 Credit-Based Usage System

* Users receive credits for generating notes
* Credit deduction on every AI request
* Prevents API misuse and controls usage efficiently

## 🔐 Firebase Authentication

* Secure user authentication
* Login and signup with Firebase
* Persistent user sessions

## ☁️ Cloud Deployment

* Fully deployed on Render
* Optimized backend hosting
* Production-ready architecture

## 📱 Responsive UI

* Mobile-friendly design
* Modern and clean user interface
* Built using Tailwind CSS
